# Executed separated-class requested-precision certificates

The new accepted-class algorithm emits an actual electronic energy interval
of width at most 2^(-p) using only exact rational arithmetic and an integer
square witness for the half-separation. Its paper correctness and operational
cost proof are SEPARATED_TWO_CENTER_FAST_v1.md. That proof gives a conservative
O((L+p+1)^3) bit-time bound and shows p=O(L) on the accepted class, so the
accepted-class cost is also polynomial in ordinary explicit input length
with binary-encoded p. It makes no claim of solving fixed-geometry molecules
at arbitrarily high p by the fast path or of efficient general many-body
computation. The universal molecular procedure remains separate.

## Actual varying-geometry instances

All four examples have rational charges 7/3 and 2/5. Put D=2^(p+4). For the
axis inputs the nuclei are at (-D,0,0),(D,0,0); for the diagonal inputs they
are at (-D,-D,0),(D,D,0), so the half-distance is irrational sqrt(2)D.
The rational witness used in both cases is d_lo=D. Each exact output is

    [-49/18 - 7/(3*2^(p+4)) - 1/2^(2p+9), -49/18].

The files contain full explicit rational numerators and denominators, not
this symbolic shorthand. The width is checked by exact cross multiplication
against 2^(-p); all four have status ACCEPTED. Nuclear repulsion is not part
of these electronic outputs. No external energy reference or reference digit
is used to generate or check them.

## Verification

Six test groups pass: floor-log power boundaries including negative
exponents; exact acceptance equality and nearby rejection; irrational and
small separation witnesses; strict finite input syntax; a p=16384 JSON
roundtrip beyond the default decimal digit cap; and replay/tamper rejection.
The strict input model rejects compressed scientific notation as well as
floats and booleans. The source explicitly disables the integer conversion
cap. CLI emission uses exclusive file creation, so a previous certificate
cannot be overwritten by an ordinary new invocation.

`verify_separated_two_center_fast_v1.py` copies only the two new Python
sources and four certificate inputs into a fresh temporary directory. It
compiles the sources, reruns all six groups, fully replays and re-emits each
certificate for exact comparison, and checks that an existing output remains
byte-for-byte unchanged when production is attempted. It passes in
0.785162333 seconds; the receipt is isolated_separated_replay_v1.json.

An independently implemented checker and review are recorded separately at
`../../logs/reproduction/two_center_fastpath_review_v1/`. It uses its own
integer-pair rational arithmetic and cross-multiplication witnesses instead
of importing the producer or its Fraction implementation. All four high-p
certificates pass with exact input, precision and producer-source binding.
The independent p=131072 verification took 0.650948 seconds, with 393231 as
the largest observed integer operand bit length and 26853376 bytes peak RSS.
It also generated and checked 25 boundary/dyadic/oblique examples from copied
source, rejected 19 certificate mutations and six malformed inputs, and
confirmed exclusive-output preservation. The receipt is
`independent_review_run_v1/review_receipt.json`; its hashes and review are
linked by the new sealing manifest. The independent reviewer also resolved
the input-size wording: even arbitrarily small positive charges cannot
remove the IMS term's necessary separation growth.

The sealed independent review also gives a second paper derivation of the
same rational envelope using chi_L=r_R/sqrt(r_L^2+r_R^2) and its partner.
These normalized distance weights have opposite-center attraction at most
z_max/d and total squared cutoff gradient at most 1/d^2. This route avoids
trigonometric evaluation even in the paper envelope proof, while retaining
the same H1 IMS and molecular spectral/form dependencies. The independent
evidence seal is INDEPENDENT_SEAL_v1.json, SHA-256
3257df6dc462b86df71fa998ebdefaacc08c99828e3ad46b649dc688181802f9.

A Homebrew checker process stalled before emitting output. The identical
checker passed under bundled Python 3.12.14; this additional environment
observation is recorded by the independent reviewer without an unsupported
cause diagnosis. Independent agreement reduces shared implementation
dependence; it is not a kernel proof of Python integer semantics or the
continuum IMS theorem.

## Exact evidence boundary and preservation

The paper interval theorem applies to all inputs in the stated accepted
class. The executable has actual finite outputs and exact replay evidence;
observed performance is listed separately from the proved polynomial bound.
Neither the program nor the molecular operator/form realization is newly
Lean verified. A DECLINED certificate cannot be presented as meeting the
requested precision merely because its coarse interval is still valid.

The new fast-path sources do not import or alter the earlier box integration
pipeline. IMS predecessor seal TWO_CENTER_IMS_SEALED_MANIFEST_v1.json has
SHA-256 c70f713c674cfe50f6e1d3a2fd2e40d1fd57d0077baabf8e5718b12502c6d12e.
All molecular and frozen original artifacts remain unchanged. The next
formal obligation for this class is the actual H1 IMS/localization and
translated molecular spectral/form bridge; the computational checker also
remains to be connected to a formal exact-integer semantics.
