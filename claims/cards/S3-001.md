# S3-001: Helium ground energy in [−2.903725202862, −2.903724370072] Ha

**Tier:** C (conditional; see §3)  **Sector:** S3  **Status:** foundation  **Depends on:** S2-002, S2-003

## 1. Formal statement
The certified inequality, with nonrelativistic, infinite-nuclear-mass helium energies in hartree:
```math
-\tfrac{1451862601431}{500000000000} \;\le\; E_\text{He} \;\le\; -\tfrac{362965546259}{125000000000},
\qquad \text{width } 8.3279\times10^{-7}.
```

- **Input:** [`trial_residual_20.json`](../../certificates/helium-ground-state/trial_residual_20.json). This is a Hylleraas-type trial $`\Phi = e^{-\alpha(r_1+r_2)}\,P(r_1,r_2,r_{12})`$ with $`\alpha=2`$, where $`P`$ is an exchange-symmetric polynomial of order 20 with 946 rational coefficients.
- **Checker:** [`check_trial.py`](../../certificates/helium-ground-state/check_trial.py). It recomputes three exact moments: $`\lVert\Phi\rVert^2`$, $`\langle\Phi,H\Phi\rangle`$, and the full continuum $`\lVert H\Phi\rVert^2`$. The first two are rationals. The third lies in $`\mathbb Q + \mathbb Q\log 2 + \mathbb Q\pi^2`$, and it is evaluated with outward-rounded 512-bit and 768-bit dyadic intervals.
- **Enclosure:** the checker then applies Temple's bound with $`\beta=-5/2`$.
- **Output:** [`certificate_residual_20_768.json`](../../certificates/helium-ground-state/certificate_residual_20_768.json) (and the 512-bit version).

## 2. Plain-English statement
The helium ground-state energy lies in an interval of width about $`8\times10^{-7}`$ hartree. Every number in the argument is an exact rational or a rigorously rounded interval, so floating-point error cannot affect the result.

## 4. Definitions audit
- The Hamiltonian is $`-\tfrac{1}{2}(\Delta_1+\Delta_2) - 2/r_1 - 2/r_2 + 1/r_{12}`$, with no nuclear motion.
- The checker computes $`\lVert H\Phi\rVert^2`$ from the continuum action of $`H`$ on $`\Phi`$. It is **not** computed from a projected finite matrix, which would give only a lower bound on the true residual.
- The reference value $`-2.903724377034\ldots`$ (Schwartz 2006) lies inside the interval. The checker does **not** use it.

## 5. What this does NOT show
- It is not a Lean-checked numerical value (open problem S2.3).
- It is not competitive in precision with non-rigorous literature values.
- [S3-002](S3-002.md) gives a tighter enclosure.
