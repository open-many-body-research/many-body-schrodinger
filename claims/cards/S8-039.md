## Literal finite dictionary and actual derivatives

The dictionary is
`P(p)=∑ α∈s (r_α:ℝ) ∏ j (p_j)^(α_j)`,
where `s` is a finite subset of `Fin 3 → ℕ` and every `r_α` is rational. The variables are the literal real distance coordinates and use their actual Pi maximum norm. The real polynomial is infinitely differentiable, and its genuine iterated Frechet derivatives are linear in these literal coefficients at every order.

For any finite real coefficient dictionary, one rational choice gives a simultaneous uniform error in orders zero, one and two on any fixed bounded coordinate box:

```lean
theorem rational_realDistancePolynomial_uniform_C2
    (s : Finset DistanceMultiIndex) (c : DistanceMultiIndex → ℝ) (b : ℝ)
    {ε : ℝ} (hε : 0<ε) :
    ∃ r : DistanceMultiIndex → ℚ,
      ∀ p : Fin 3 → ℝ, ‖p‖≤b → ∀ k : Fin 3,
        ‖iteratedFDeriv ℝ (k:ℕ) (realDistancePolynomial s c) p-
          iteratedFDeriv ℝ (k:ℕ) (realDistancePolynomial s (fun α => (r α:ℝ))) p‖<ε
```

The order-zero continuous multilinear norm is the scalar value norm. Orders one and two are the actual real gradient and Hessian operator norms. No formal derivative family is substituted for these maps.

The genuine finite representation of the canonical real Taylor polynomial is proved, rather than supplied as a premise:

```lean
theorem realTaylorPolynomial_finite_distance_dictionary (f : (Fin 3 → ℝ) → ℝ)
    (a : Fin 3 → ℝ) (N : ℕ) :
    ∃ s : Finset DistanceMultiIndex, ∃ c : DistanceMultiIndex → ℝ,
```

Every actual multilinear diagonal is expanded over the actual real coordinate basis. A literal `MvPolynomial (Fin 3) ℝ` represents the resulting finite word sum, including the actual center translations `p_j−a_j`. Its genuine finite monomial support is then converted to the unshifted distance dictionary above. Thus the representation applies to the actual canonical Taylor polynomial for any function, center and cutoff.

## Approximation of the actual profile

For a genuine complex analytic profile `f`, the real scalar restriction is the literal
`ambientRealScalarProfile f p = (f (ambientRealCast p)).re`.
The actual coordinate cast and real-output continuous linear maps identify every ordered real derivative with the real part of the actual complex derivative. The canonical real Taylor polynomial is exactly the real part of the SAME complex polynomial on the real slice, globally. Genuine complex derivative-difference operator norms bound the real ones.

Consequently the S8-037 coupled remainder, genuine finite representation and rational density yield an approximation of the actual profile, with no approximation premise:

```lean
theorem rational_ambient_profile_uniform_C2
    {f : (Fin 3 → ℂ) → ℂ} {a : Fin 3 → ℝ} {R C : ℝ}
    (hR : 0<R) (hdata : ComplexDistanceTaylorData f (ambientRealCast a) R C)
    (hf : AnalyticOnNhd ℂ f (ball (ambientRealCast a) R))
    {ε : ℝ} (hε : 0<ε) :
    ∃ s : Finset DistanceMultiIndex, ∃ r : DistanceMultiIndex → ℚ,
      ∀ p : Fin 3 → ℝ, ‖p-a‖≤R/8 → ∀ k : Fin 3,
        ‖iteratedFDeriv ℝ (k:ℕ) (ambientRealScalarProfile f) p-
          iteratedFDeriv ℝ (k:ℕ) (realDistancePolynomial s (fun α => (r α:ℝ))) p‖<ε
```

The proof first chooses one sufficiently long canonical Taylor cutoff so that all three actual derivative errors are below half the tolerance throughout the closed inner box. A single rational coefficient family then approximates that very polynomial in the same three norms on a bounded box containing it. The triangle inequality gives the stated full tolerance for the actual profile. Rational density and the genuine geometric Taylor limit are existential; this theorem supplies no algorithmic rate, computable degree or certified coefficient-selection procedure.
