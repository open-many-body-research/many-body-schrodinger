# S1-002: No bound state for a non-attracting nucleus

**Tier:** L  **Sector:** S1  **Status:** foundation  **Depends on:** none

## 1. Formal statement
`TheoremT.Continuum.nonpositive_charge_zero_spectrum_trivial_kernel`, in [`CoulombUnboundNonpositive_v1.lean`](../../lean/Foundation/CoulombUnboundNonpositive_v1.lean):
```lean
theorem nonpositive_charge_zero_spectrum_trivial_kernel {N : ℕ} (hN : 0 < N)
    {Z : ℝ} (hZ : Z ≤ 0) :
    variationalGroundEnergy N Z = 0 ∧ formGroundEnergy N Z = 0 ∧
    (0 : ℂ) ∈ TheoremT.OperatorTheory.unboundedSpectrum (coulombPartialOperator N Z) ∧
    ∀ ψ : SpinSpace N, hamiltonianGraph N Z ψ 0 → ψ = 0
```

## 2. Plain-English statement
Suppose there is at least one electron and the nucleus does not attract ($Z \le 0$). Then:
- the ground energy is exactly 0;
- 0 is in the spectrum;
- no nonzero wavefunction has energy exactly 0, so there is no bound state.

## 3. Hypotheses
The hypotheses $N \ge 1$ and $Z \le 0$ define the scope. Nothing is assumed beyond them.

## 4. Definitions audit
The objects are the same as in [S1-001](S1-001.md). `hamiltonianGraph N Z ψ 0` means $H\psi = 0$ with $\psi$ in the weak-$H^2$ fermionic domain.

## 5. What this does NOT show
It says nothing about $Z > 0$. The result is elementary.
