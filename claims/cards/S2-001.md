theorem coulomb_rankOne_directed_spectral_enclosure (N : ℕ) (Z : ℝ)
    (l : FermionicSpace N →L[ℂ] ℂ) (β C : ℝ) (hC : 0 ≤ C)
    (hbound : ∀ x : (coulombPartialOperator N Z).domain,
      β * ‖(x : FermionicSpace N)‖^2 ≤

          C * ‖l (x : FermionicSpace N)‖^2)

    (hU : (inner ℂ (ψ : FermionicSpace N) (coulombPartialOperator N Z ψ)).re ≤ U)

    ((L-r/(β-U) : ℝ) : EReal) ≤ spectralGroundEnergy N Z ∧

## 2. Plain-English statement
Suppose the Hamiltonian is bounded below by $`\beta`$, up to a rank-one correction. Suppose also you have a normalized trial state whose energy $`\mu`$ is certified to lie in $`[L, U]`$ with $`U<\beta`$, and whose residual satisfies $`\lVert(H-\mu)\psi\rVert^2 \le r`$. Then the true ground energy lies in $`[L - r/(\beta - U),\, U]`$. This is Temple's inequality, stated and proved for the actual unbounded continuum operator.

## 4. Definitions audit
The objects are those of [S1-001](S1-001.md). The residual uses the actual operator applied to the actual domain vector, not a finite-dimensional projection.

## 5. What this does NOT show
- It does not produce a trial state or a certificate.
- It does not prove the comparison `hbound` for $`N \ge 3`$.
- The mathematics is Temple (1928) and Kato (1949).
