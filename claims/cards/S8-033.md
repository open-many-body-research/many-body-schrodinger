For every `Z ≥ 2`, one actual normalized scalar Coulomb ground state and its original physical representative have explicit local Taylor-polynomial truncation budgets for all three literal nuclear and pair ambient distance functions: the first profile, second profile and combined function. Both nuclear indices and every admissible positive scale are included. The coefficients are genuine complex derivatives at the stated center; the conclusion includes a genuine local `HasFPowerSeriesAt`, canonical sums to the actual function throughout the quarter polydisc, and uniform geometric error in polynomial order.

For any one of the three profiles `f`, let `r` be its full original distance radius and `C` its proved full-domain norm bound. On the quarter polydisc, the polynomial of terms with degrees strictly below `N` satisfies

```text
||f(q) − Taylor_N(f,a)(q)|| ≤ (3/2) C (1/3)^N.
```

Every genuine complex derivative field also has its own fixed-center Taylor polynomial, with true multilinear operator-norm error

```text
||D^k f(q) − Taylor_N(D^k f,a)(q)|| ≤
  3 C (2 exp(1)/r)^k k! (2/3)^N.
```

This includes the first and second derivative fields and all higher orders. These derivative-field approximants are stated directly; the theorem does not identify them with derivatives of one truncated value polynomial. No rational, computable or certified approximate coefficients are selected.

## Exact coefficients, sums and error predicates

For complex normed spaces `E,F`, with complete target `F`, the actual coefficient and polynomial functions are:

```lean
def complexTaylorCoefficient (f : E → F) (a : E) (n : ℕ) (h : E) : F :=
  (n.factorial:ℂ)⁻¹ • iteratedFDeriv ℂ n f a (fun _ => h)

def complexTaylorPolynomial (f : E → F) (a : E) (N : ℕ) (q : E) : F :=
  ∑ n∈Finset.range N, complexTaylorCoefficient f a n (q-a)
```

```lean
def ComplexDistanceTaylorData (f : E → F) (a : E) (R C : ℝ) : Prop :=
  (∃ p : FormalMultilinearSeries ℂ E F, HasFPowerSeriesAt f p a ∧
    ∀ n : ℕ, ∀ h : E, p n (fun _ => h)=complexTaylorCoefficient f a n h) ∧
  (∀ q : E, ‖q-a‖<R/4 →
    HasSum (fun n => complexTaylorCoefficient f a n (q-a)) (f q) ∧
    ∀ N : ℕ, ‖f q-complexTaylorPolynomial f a N q‖≤(3/2)*C*(1/3:ℝ)^N) ∧
  (∀ k : ℕ, ∀ q : E, ‖q-a‖<R/4 →
    HasSum (fun n => complexTaylorCoefficient (iteratedFDeriv ℂ k f) a n (q-a))
      (iteratedFDeriv ℂ k f q) ∧
    ∀ N : ℕ, ‖iteratedFDeriv ℂ k f q-
      complexTaylorPolynomial (iteratedFDeriv ℂ k f) a N q‖≤
      3*C*(2*Real.exp 1/R)^k*(k.factorial:ℝ)*(2/3:ℝ)^N)
```

## Genuine analytic derivation and physical applicability

The generic theorem selects local power-series data from actual holomorphic data at the true center. For an actual displacement `h`, it restricts the same function to the complex line `z ↦ a+z•h`. Positive line radius `ρ>1` and the proved condition `ρ‖h‖<r` place its whole closed disc in the actual full domain. The unchanged Cauchy formula supplies a genuine line power series. One-dimensional power-series uniqueness identifies it with the linear restriction of the same selected multivariate series. The pinned factorial derivative formula identifies its diagonal coefficients with `(n!)⁻¹ D^n f(a)[h,…,h]`, including order zero.

The actual Cauchy circle norm estimate gives coefficient norm at most `C*(ρ⁻¹)^n`. Its genuine sum at `z=1` is `f(a+h)`. The checked geometric-tail theorem therefore gives the explicit error `C*(ρ⁻¹)^N/(1−ρ⁻¹)`. On the quarter domain, the fixed choice `ρ=3` produces `(3/2)C3⁻N`. No remainder or coefficient norm estimate is assumed as physical input.

For the derivative-field conclusion, the proved generic Cauchy theorem supplies the true norm bound `C*(2 exp(1)/r)^k*k!` and analyticity of `D^k f` on the half domain. A radius-`3/2` line disc through any original quarter-domain displacement remains in that half domain. Applying the same actual sum/tail proof produces the displayed `3C_k(2/3)^N` derivative-field error. The codomain is the true continuous multilinear-map space, so these errors are genuine operator-norm errors.

The nuclear consumer obtains actual separate-profile analyticity and bounds from the recovered axial data of the same normalized physical difference, together with actual nuclear combined reconstruction. The pair consumer uses the unchanged original pair reconstruction, including its actual separate analytic profiles and full-domain bounds. The final physical theorem invokes the actual S8-029 endpoint, preserves its same normalized `f/u`, original scalar Hamiltonian graph, spectral minimum, weak `H²` decay, physical almost-everywhere representative, reality, original exchange and full orthogonal invariance, Lipschitz/Moser facts, and every original descent and reconstruction fact. It discharges all analytic and bounded-domain premises for that same original representative at all selected indices/scales. No replacement Hamiltonian, independent profile family or assumed Taylor remainder is used.
