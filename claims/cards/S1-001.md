# S1-001: Self-adjointness and ground-energy identification for atoms

**Tier:** L  **Sector:** S1  **Status:** foundation  **Depends on:** none

## 1. Formal statement

`TheoremT.Continuum.coulomb_shared_continuum_foundation` in [`lean/Foundation/CoulombSpectralFoundation_v3.lean`](../../lean/Foundation/CoulombSpectralFoundation_v3.lean):

```lean
theorem coulomb_shared_continuum_foundation (N : ℕ) (Z : ℝ) :
    IsSelfAdjoint (coulombPartialOperator N Z) ∧
    ((coulombPartialOperator N Z).domain : Set (FermionicSpace N)) =
      {ψ | ∀ σ, HasH2 (ψ.val σ)} ∧
    ∃ E : ℝ, variationalGroundEnergy N Z = (E : EReal) ∧
      formGroundEnergy N Z = (E : EReal) ∧
      spectralGroundEnergy N Z = (E : EReal) ∧
      -(N : ℝ) * (max Z 0)^2 / 2 ≤ E ∧ E ≤ 0 ∧
      (E : ℂ) ∈ TheoremT.OperatorTheory.unboundedSpectrum (coulombPartialOperator N Z) ∧
      ∀ z ∈ TheoremT.OperatorTheory.unboundedSpectrum (coulombPartialOperator N Z),
        z.im = 0 ∧ E ≤ z.re
```

There is a companion theorem, `TheoremT.Continuum.scalar_coulomb_continuum_foundation` ([`ScalarCoulombFoundation_v1.lean`](../../lean/Foundation/ScalarCoulombFoundation_v1.lean)). It states the same for the operator on $L^2(\mathbb R^{3N})$ with no symmetry constraint, and adds that the $H^1$ form is defined exactly on $H^1$.

## 2. Plain-English statement

Consider an atom with $N$ electrons and one fixed nucleus of charge $Z$ at the origin, in atomic units, with spin and Fermi statistics. For every $N$ and every real $Z$:

- **Self-adjoint on $H^2$.** Its Hamiltonian is a self-adjoint operator whose domain is exactly the antisymmetric wavefunctions with square-integrable second derivatives.
- **Three ground energies agree.** The variational ground energy (over the operator domain), the quadratic-form ground energy (over $H^1$) and the bottom of the spectrum are the same number $E$.
- **Bounds on $E$.** That number satisfies $-N\max(Z,0)^2/2 \le E \le 0$.
- **Spectrum.** $E$ belongs to the spectrum, and the whole spectrum is real and lies at or above $E$.

## 3. Hypotheses

None beyond `N : ℕ` and `Z : ℝ`. The theorem is unconditional, and it does not assume binding, attainment, uniqueness or a gap.

## 4. Definitions audit

All definitions live in [`ContinuumFoundation_v1.lean`](../../lean/Foundation/ContinuumFoundation_v1.lean) unless noted.

- **Configuration space.** `Configuration N` is `EuclideanSpace ℝ (Fin N × Fin 3)`, carrying Lebesgue measure (`volume`).
- **Hilbert spaces.** `SpatialL2 N` is Mathlib's `Lp ℂ 2 volume`. `SpinSpace N` is the $\ell^2$ direct sum, over spin configurations `Fin N → Fin 2`, of copies of `SpatialL2 N`. That is exactly $L^2((\mathbb R^3\times\{\uparrow,\downarrow\})^N)$, with counting measure in spin.
- **Antisymmetry.** `fermionicSubspace N` imposes $\psi(\pi\cdot x, \sigma\circ\pi) = \operatorname{sgn}(\pi)\,\psi(x,\sigma)$ for every permutation $\pi$, as an identity in $L^2$ (via measure-preserving pullback). This is simultaneous space–spin antisymmetry.
- **Potential.** `coulombPotential N Z x` is $-Z\sum_i |x_i|^{-1} + \sum_{i<j}|x_i-x_j|^{-1}$. There is no softening or cutoff. Its values on the null collision set are irrelevant.
- **Sobolev conditions.** `WeakPartial f g k` is the distributional derivative, tested against all real $C_c^\infty$ functions. `HasH2` requires all first and second weak derivatives to exist in $L^2$, which is the standard $H^2$.
- **Operator.** `scalarHamiltonianGraph` requires every mixed second weak derivative to exist, and defines the output a.e. as $-\tfrac12\sum_k \partial_k^2 f + V f$. `coulombPartialOperator` ([`CoulombOperatorCore_v2.lean`](../../lean/Foundation/CoulombOperatorCore_v2.lean)) is the `LinearPMap` whose graph is exactly this relation on the fermionic space. That the operator is defined on all of $H^2$ is **proved** (the domain equation above), not assumed.
- **Self-adjointness.** `IsSelfAdjoint` is Mathlib's notion for `LinearPMap`, via the adjoint.
- **Spectrum.** `unboundedSpectrum A` ([`UnboundedResolvent_v2.lean`](../../lean/Foundation/UnboundedResolvent_v2.lean)) is the set of $z$ for which $A - z$ has **no** bounded two-sided inverse into `A.domain`. This is the textbook definition for closed operators. It is a project definition because Mathlib has none for unbounded operators, so the review requested in open problem **S1.1** is about exactly this point.
- **Ground energies.** They are infima in `EReal`, so none is assumed finite a priori; finiteness is part of the conclusion.

## 5. What this does NOT show

- It covers atoms only, not molecules (multiple nuclei). That extension is S1.2.
- It says nothing about the essential spectrum (HVZ), existence of bound states for $Z>0$, or multiplicity.
- It is not new mathematics. It is Kato (1951), formalized.
