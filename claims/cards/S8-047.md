# S8-047 — Explicit dyadic coefficient rounding for true finite distance polynomials

**Sector:** S8 — regularity and approximation
**Tier:** proposed L
**Status:** proposed; focused named kernel checks and independent AI applicability/card/receipt audit passed; full committed verification and human maintainer statement review pending

**Sources:** `lean/ManyBody/S8/Internal/DyadicDistanceRounding.lean`, `lean/ManyBody/S8/DyadicDistanceCoefficientApproximation.lean`

Literal floor rounding at denominator `2^b` gives one actual rational coefficient for every original real coefficient. The same resulting finite polynomial approximates the original finite distance polynomial in its real value, first derivative and second derivative operator fields, with an explicit finite-support/radius error bound. For the true canonical Taylor polynomial of order cutoff `N`, the actual dictionary has at most `N^3` entries and total degree below `N`; on the real distance box `||q||≤2`, denominator exponent `b=p+4+7*N` makes every rounding error at most `(1/2)^p`.

Here `b` is the denominator exponent and specifies a dyadic grid spacing. It is not a total encoding-bit bound: integer numerator magnitudes depend on the original coefficients. The floor term is a literal mathematical function of arbitrary real inputs; no procedure for evaluating the original coefficients or their integer floors is proved.

The exact rounding definition and its proved one-sided error, including negative coefficients and `b=0`, are:

```lean
def dyadicDistanceCoefficient (b : ℕ) (c : ℝ) : ℚ :=
  (⌊(2 : ℝ)^b*c⌋ : ℚ)/(2 : ℚ)^b
```

```lean
theorem dyadicDistanceCoefficient_error (b : ℕ) (c : ℝ) :
    0 ≤ c-(dyadicDistanceCoefficient b c : ℝ) ∧
      c-(dyadicDistanceCoefficient b c : ℝ) < (1/2 : ℝ)^b
```

The explicit actual support/radius budget is:

```lean
def distanceC2DyadicRoundingBudget (s : Finset DistanceMultiIndex) (R : ℝ) : ℝ :=
  ∑ α ∈ s, 16*(4*(1+max 0 R))^(∑ j : Fin 3, α j)
```

For each actual monomial, true derivatives give
`||D^k monomial_α(q)||≤16*[4*(1+R)]^(sum_j α_j)` for `R≥0`, `||q||≤R`, and `k=0,1,2`. This is proved from the genuine binomial product derivative formula and coordinate-power induction. The factor 16 and exponential degree factor are safe upper bounds; no assumed monomial jet or polynomial derivative bound is used. Linearity of the actual iterated derivative of the finite polynomial, the floor error and the norm of the finite sum give:

```lean
theorem dyadic_realDistancePolynomial_uniform_C2
    (s : Finset DistanceMultiIndex) (c : DistanceMultiIndex → ℝ) (R : ℝ) (b : ℕ)
    {p : Fin 3 → ℝ} (hp : ‖p‖ ≤ R) (k : Fin 3) :
    ‖iteratedFDeriv ℝ (k : ℕ) (realDistancePolynomial s c) p-
      iteratedFDeriv ℝ (k : ℕ)
        (realDistancePolynomial s (fun α => (dyadicDistanceCoefficient b (c α) : ℝ))) p‖ ≤
      distanceC2DyadicRoundingBudget s R*(1/2 : ℝ)^b
```

The public consumer rounds the exact canonical support and its actual real coefficients from S8-048, with those functions fixed before every denominator exponent. It does not assume a finite representation of the Taylor target:


The true canonical support's degree and cardinality yield the sharper displayed finite-order form:

```lean
theorem realTaylor_dyadic_rounding_uniform_C2
    (f : (Fin 3 → ℝ) → ℝ) (a : Fin 3 → ℝ) (N b : ℕ) (R : ℝ)
    {q : Fin 3 → ℝ} (hq : ‖q‖ ≤ R) (k : Fin 3) :
    ‖iteratedFDeriv ℝ (k : ℕ) (realTaylorPolynomial f a N) q-
      iteratedFDeriv ℝ (k : ℕ) (realTaylorDyadicDistancePolynomial f a N b) q‖ ≤
      16*(N : ℝ)^3*(4*(1+max 0 R))^N*(1/2 : ℝ)^b
```

A separate theorem gives the same rate on a centered box `||q-a||≤r`, using the literal enclosing radius `||a||+r`. These are actual Pi max norms on the three real distance coordinates, and actual continuous multilinear operator norms for their iterated real derivatives.

The strongest explicit denominator schedule is:

```lean
theorem realTaylor_dyadic_rounding_explicit_bits_C2
    (f : (Fin 3 → ℝ) → ℝ) (a : Fin 3 → ℝ) (N p : ℕ)
    {q : Fin 3 → ℝ} (hq : ‖q‖ ≤ 2) (k : Fin 3) :
    ‖iteratedFDeriv ℝ (k : ℕ) (realTaylorPolynomial f a N) q-
      iteratedFDeriv ℝ (k : ℕ)
        (realTaylorDyadicDistancePolynomial f a N (p+4+7*N)) q‖ ≤ (1/2 : ℝ)^p
```

At radius two, `G=4*(1+2)=12≤16`. The actual budget is at most `16*N^3*G^N`; `N≤2^N` gives this at most `2^(4+7*N)`. Multiplying by `(1/2)^(p+4+7*N)` proves the stated rounding error, with the SAME rounded polynomial for every evaluation point and derivative order. The zero-order dictionary is empty and both the original and rounded Taylor polynomials vanish. No positive-order premise is needed.

The support and coefficients depend on the fixed original function, center and truncation cutoff. Every precision exponent is supplied after that same canonical dictionary, and the bound is uniform over all points in the stated box and all three derivative orders. The finite-polynomial budget depends only on its support and enclosing radius, not on the coefficient values or rounding exponent.

The target of these new error estimates is the actual finite canonical Taylor polynomial. Comparison with an original analytic profile requires the separate true Taylor remainder statements of S8-045/S8-048; this card does not assert a total analytic-profile or physical-wavefunction error by itself. The statement gives no algorithm for extracting arbitrary original real coefficients, numerator magnitude or bit complexity, physical weak H2 composition error, global finite dictionary, solver termination, full Rung2 or T completion.
