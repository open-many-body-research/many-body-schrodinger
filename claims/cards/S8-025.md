## Genuine quantitative Cauchy proof

The supporting generic theorem `holomorphic_fderiv_ball_bound` assumes only an actual bounded holomorphic map `f:E→F` on a ball and enough margin `‖x-a‖+d<R`. For every unit vector `v`, it restricts `f` to the genuine complex line `z ↦ x+z•v`. It proves the line disc stays in the actual ball, then applies the pinned Mathlib one-variable Cauchy estimate. The true chain rule identifies the line derivative with `fderiv ℂ f x v`, giving the operator bound `‖fderiv ℂ f x‖≤C/d`.

For each positive fixed `n`, `holomorphic_iteratedFDeriv_half_ball_bound` applies this first-order estimate to the genuine analytic derivative fields on `n` successively smaller balls, with `d=R/(2*n)`. It derives the intermediate actual bound `C*(2*n/R)^n` on the half ball. A proved Stirling consequence `n^n≤exp(1)^n*n!` supplies the explicit bound
