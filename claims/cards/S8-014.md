# S8-014: Physical eigenstate local Lipschitz bound from the original norm

**Sector:** S8 (regularity and approximation)
**Proposed tier:** L
**Status:** proposed; focused kernel checks passed; human maintainer statement review pending
**Source:** [`PhysicalEigenstateLipschitzNormBound.lean`](../../lean/ManyBody/S8/PhysicalEigenstateLipschitzNormBound.lean)
**Principal declaration:** `ManyBody.S8.coulomb_spin_local_lipschitz_original_norm_bound`

## Statement

Fix an electron count `N > 0`, real nuclear charge `Z`, real energy `E`, and a configuration-space ball radius `A`. A common finite nonnegative constant is chosen before the eigenfunction. Every eigenfunction of the original physical Coulomb Hamiltonian has a globally locally Lipschitz representative whose Lipschitz constant on the closed ball about the origin of radius `A` is at most that common constant times the original full spin-state L2 norm. The same constant works for every spin component. The representative also has the physical almost-everywhere equality, fermionic permutation law, and full spin Moser bound.

The constant may depend on `N`, `Z`, `E`, and `A`. It is obtained existentially by Banach–Steinhaus. This statement does not give a numerical formula or a computable method for obtaining that constant. In particular, it does not assert uniformity as the charge, energy, or radius vary.

Taking `A = 1` gives a fixed geometric radius and a state-independent coefficient for the local Lipschitz amplitude needed by physical KS initialization. The useful geometric case is positive `A`; the exact formal statement allows any real `A`, including empty closed balls.

## Exact Lean statements

Principal full-spin result:

```lean
theorem coulomb_spin_local_lipschitz_original_norm_bound {N : ℕ} (hN : 0 < N)
    (Z E A : ℝ) :
    ∃ C : ℝ≥0, ∀ ψ : SpinSpace N,
      hamiltonianGraph N Z ψ ((E : ℂ) • ψ) →
      ∃ u : SpinConfiguration N → Configuration N → ℂ,
        (∀ σ, LocallyLipschitz (u σ)) ∧
        (∀ᵐ x ∂volume, ∀ σ, ψ σ x = u σ x) ∧
        (∀ π : Equiv.Perm (Fin N), ∀ σ, ∀ x,
          u (permuteSpin π σ) (permuteSpace π x) = permutationSign π • u σ x) ∧
        (∀ x, Real.sqrt (∑ σ : SpinConfiguration N, ‖u σ x‖^2) ≤
          coulombMoserBoundCoefficient N Z E * ‖ψ‖) ∧
        ∀ σ, LipschitzOnWith (C * ‖ψ‖₊) (u σ) (Metric.closedBall 0 A)
```

Scalar physical result:

```lean
theorem scalar_coulomb_local_lipschitz_original_norm_bound {N : ℕ} (hN : 0 < N)

      scalarHamiltonianGraph N Z f ((E : ℂ) • f) →

        (∀ x, ‖u x‖ ≤ coulombMoserBoundCoefficient N Z E * ‖f‖) ∧
        LipschitzOnWith (C * ‖f‖₊) u (Metric.closedBall 0 A)
```

## Premises and quantifier order

- **Assumed:** `0 < N`; `Z`, `E`, and `A` are fixed real parameters.
- **Assumed:** the actual graph statement `hamiltonianGraph N Z ψ ((E : ℂ) • ψ)` in the full-spin theorem, or `scalarHamiltonianGraph` in its scalar versions.
- **Proved:** the constant `C : ℝ≥0` precedes the original state and every spin component. It depends only on the fixed parameter tuple.
- **Proved:** the physical representative, its local Lipschitz regularity, AE equality, full permutation law, and Moser bound are constructed from the original graph in the principal theorem. No representative, input derivative, gradient bound, or Lipschitz constant is supplied.
- **Assumed only in the compatibility theorem:** a continuous representative `u` with the displayed actual AE equality. Pointwise uniqueness transfers the same bound to every such representative.
- **Proved:** the estimate uses the original full spin-space norm, with no factor for the number of spin configurations.

No ground-state existence, spectral separator, eigenvalue isolation, eigenspace dimension, charge sign, or normalization premise is added. If the physical eigenspace is zero, the statement applies to its zero state.

## Definitions and proof audit

`SpinSpace N`, `SpatialL2 N`, `Configuration N`, `hamiltonianGraph`, and `scalarHamiltonianGraph` are the existing frozen physical definitions. The operator is the original atomic Coulomb Hamiltonian with kinetic coefficient `-1/2`, nuclear attraction, electron-pair repulsion, and the original exact weak H2 graph domain. The spin theorem retains simultaneous spin/spatial fermionic antisymmetry.

The proof constructs the literal scalar eigenspace as the inverse image of the physical Coulomb graph under the continuous linear map `f ↦ (f, E f)`. Its closedness follows from the frozen self-adjoint physical operator's closed graph. Consequently the eigenspace, with its original L2 norm, is a complete normed complex vector space.

For each eigenspace element the frozen physical regularity theorem supplies a unique continuous, locally Lipschitz representative with the original Moser point bound. Addition and scalar multiplication of those representatives agree pointwise: their actual L2 coercions agree AE, and continuous functions that agree AE for the physical volume measure agree everywhere. Evaluation at any configuration point is therefore a complex-linear map on the physical eigenspace and is bounded by `coulombMoserBoundCoefficient N Z E` times the original norm.

The family of continuous linear maps consists of the literal normalized differences

`(u_f(x) - u_f(y)) / dist(x,y)`

for distinct `x,y` in the fixed compact closed configuration ball. Each state has bounded difference quotients on that compact set because its actual representative is locally Lipschitz. Banach–Steinhaus then bounds the operator norms of the entire family with one constant before the state. Multiplying by `dist(x,y)` yields the stated Lipschitz estimate. The diagonal case is proved directly.

The spin theorem applies the common scalar bound at the same parameters to each actual spin component. Each component norm is bounded by the original full spin norm. The existing physical full-spin representative retains the permutation law and square-sum Moser bound. No operator or coordinate space is redefined, and no finite-dimensional eigenspace assumption is used.
