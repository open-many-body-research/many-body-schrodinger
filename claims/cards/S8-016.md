# S8-016: One finite physical collision-chart family at every nonzero radius

**Proposed tier:** L. **Status:** kernel checks passed; human statement review pending. **Sector:** S8.

For every positive relative neighborhood width, one finite set of unit physical spectator centers covers the entire two-electron unit configuration sphere using the actual collision-free set, both nuclear neighborhoods and the original half-sum pair neighborhood. The same finite family covers every positive radius by literal configuration scaling, hence every configuration except the triple origin. No Hamiltonian, eigenfunction, state-dependent estimate or assumed chart coverage is an input.

For widths at most 1/16, each nuclear neighborhood excludes the other nucleus and the electron pair collision; each pair neighborhood excludes both nuclear collisions. These exclusions are proved for every point of the respective neighborhood, including its selected collision.

## Actual coordinates and quantifier order

`Configuration 2` and `Position` are the frozen Euclidean physical spaces, and `position x i` is the actual original electron position. The pair center is `(position x 0 + position x 1)/2`, matching the restored c=1 pair coordinate. On the unit configuration sphere a pair-collision center has norm `1/sqrt(2)`, which is explicitly used in the pair-neighborhood center.

`annularPhysicalChartCover eta t` is the union of the actual collision-free set with nuclear neighborhoods for indices0 and1 and the pair neighborhood. `scaledAnnularPhysicalChartCover rho eta t` is its preimage under the literal linear scaling `x ↦ rho^(-1) • x`. The finite centers precede every positive radius and every original configuration. The statement is geometric and does not assume that any analytic estimate is valid on those neighborhoods.
