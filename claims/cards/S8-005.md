          (∀ᵐ x ∂volume, ∀ σ, ψ σ x = u σ x) ∧
          (∀ π : Equiv.Perm (Fin 2), ∀ σ, ∀ x,
            u (permuteSpin π σ) (permuteSpace π x) = permutationSign π • u σ x) ∧

## 2. Plain-English statement

For a two-electron Coulomb eigenfunction in the existing physical Hamiltonian graph, a smooth compact cutoff inside the displayed nuclear chart has first weak derivatives in the four KS directions and all spectator directions, and second weak derivatives in the ordered KS/KS directions. Their squared L² norms are controlled by the local squared L² norm of the physical representative pulled back through the actual KS lift.

The theorem also supplies a common locally Lipschitz representative for all spin components, almost-everywhere equality with the physical L² state, the pointwise simultaneous spin/spatial permutation law, and the existing global Coulomb Moser bound. The only solution premise is the original physical eigenfunction graph. There is no separately supplied transformed PDE, potential bound, KS local-L² premise, or KS input-derivative premise.

## 4. Definitions and coefficient audit

The Hamiltonian graph uses the existing continuum two-electron Coulomb expression

```math
-\frac12(\Delta_{x_0}+\Delta_{x_1})
-\frac{Z}{\lVert x_0\rVert}-\frac{Z}{\lVert x_1\rVert}
+\frac{1}{\lVert x_0-x_1\rVert},
```

with its actual L² classes, weak partials, and fermionic subspace. The output representative obeys the existing permutation definitions; this is not a symmetry assumption on an unrelated function.

`NuclearKSSpace (0 : Fin 2)` is the existing product of the four-dimensional KS space and `SpectatorConfiguration (0 : Fin 2)`, with its actual product norm and volume. Write `Y = q.1` and `x = nuclearKSLift (0 : Fin 2) q`. The literal chart predicates are:

```lean
nuclearChartScaledOpen r t0 =
  {q | ‖q.1‖ ^ 2 < r / 16 ∧
    ‖position (nuclearKSLift (0 : Fin 2) q) (1 : Fin 2) - t0‖ < r / 4}

nuclearChartOpen t0 =
  {q | ‖q.1‖ < (1 / 4 : ℝ) ∧
    ‖position (nuclearKSLift (0 : Fin 2) q) (1 : Fin 2) - t0‖ < (1 / 4 : ℝ)}
```

The spectator condition refers to the literal other-electron physical position, without an assumed spectator isometry. The existing KS identity gives `‖position x 0‖ = ‖Y‖²`. On the closed scaled chart, the proved geometric bounds include

```math
\lVert x_1\rVert\ge\frac{3r}{4},\qquad
\lVert x_0\rVert\le\frac{r}{16},\qquad
\lVert x_0-x_1\rVert\ge\frac{11r}{16}.
```

Thus the chart includes the selected nuclear collision and excludes the other nuclear and electron-pair collisions, as required by the actual coefficient patch. The exact existing coefficient is

```math
B(q)=-8Z+8\lVert Y\rVert^2
 \left(-\frac{Z}{\lVert x_1\rVert}
       +\frac{1}{\lVert x_0-x_1\rVert}-E\right).
```

The helpers prove

```math
\lVert B(q)\rVert\le
 \frac{26}{3}|Z|+\frac{8}{11}+\frac{r|E|}{2}
 \le \frac{26}{3}|Z|+\frac{8}{11}+\frac{|E|}{2}
 \quad(0<r\le1).
```

Continuity on the coefficient patch and the actual scalar eigenfunction graph give the homogeneous weak equation for the existing `splitGrushin 4 oscillatorBasis B`. The physical coefficient `c = 4` accounts for the denominator `16c = 64` in the spectator derivative estimate.

The output `U` equals `χ · (u σ ∘ nuclearKSLift 0)` almost everywhere. `WeakProductL2Directional` asserts genuine weak derivatives of this same cutoff function in the existing coordinate directions. Each `hyy j k` is the weak derivative of `gy j` in `yDir k`. These are continuum L² norms and mathematical existence witnesses, not finite matrices or an executable derivative-selection algorithm.
