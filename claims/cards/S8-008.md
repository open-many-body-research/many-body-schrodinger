# S8-008: Physical two-electron pair KS charts have genuine joint local weak H²

**Proposed tier:** L, kernel checked; human maintainer review pending. **Sector:** S8. **Proposed status:** proposed. Focused source checks and this submission do not establish maintainer acceptance.

The original two-electron physical Coulomb graph supplies local weak H² of its electron-pair KS pullback on the exact coefficient patch, including the selected pair collision. The construction reconstructs both original positions through the existing orthogonal Hadamard map. It derives the transformed equation and its exact coefficient from the original physical equation; it assumes no transformed PDE or transformed derivative witnesses.

For every ordered direction pair it constructs a second weak L² witness. This includes both mixed orders and spectator/spectator directions.

## 2. Geometry, coefficient, and measure audit

[`PairKSGeometry.lean`](../../lean/ManyBody/S8/Internal/PairKSGeometry.lean) uses the existing physical `twoElectronRelativeEquiv`, whose orthogonal Hadamard coordinates are

```math
T=(x_0+x_1)/\sqrt2,\qquad R=(x_0-x_1)/\sqrt2.
```

The existing map is an isometry, is its own inverse, and preserves canonical six-dimensional Lebesgue measure. These properties are proved in the frozen [`TwoElectronRelativeCoordinates_v1.lean`](../../lean/Foundation/TwoElectronRelativeCoordinates_v1.lean); its genuine weak first-derivative transport is preserved in [`TwoElectronRelativeSobolev_v1.lean`](../../lean/Foundation/TwoElectronRelativeSobolev_v1.lean).

The chart space and actual lift are

```lean
abbrev PairKSSpace := NuclearKSSpace (1 : Fin 2)
def pairKSLift (q : PairKSSpace) : Configuration 2 :=
  twoElectronRelativeEquiv (nuclearKSLift (1 : Fin 2) q)
```

Thus `R = ksMap Y`, and the spectator is the actual center coordinate `T`. The original positions are proved to be

```math
x_0=(T+\operatorname{KS}(Y))/\sqrt2,\qquad
x_1=(T-\operatorname{KS}(Y))/\sqrt2.
```

The actual selected pair distance is `sqrt(2) * ‖Y‖²`. The repulsion is therefore `1/(sqrt(2)*‖Y‖²)` off `Y=0`. The original kinetic metric remains orthogonal, so the principal KS operator is `Δ_Y + 4‖Y‖² Δ_T`. [`PairKSLaplacian.lean`](../../lean/ManyBody/S8/Internal/PairKSLaplacian.lean) proves its Hadamard Laplacian covariance by genuine second directional derivatives and bilinear trace cancellation.

The actual cleared coefficient is

```math
B(Y,T)=\frac8{\sqrt2}
 +8\lVert Y\rVert^2
 \left[-Z\left(\frac1{\lVert x_0\rVert}
                  +\frac1{\lVert x_1\rVert}\right)-E\right].
```

The source proves `B(q) = 8‖Y‖² (coulombPotential 2 Z (pairKSLift q) - E)` off `Y=0`. At `Y=0`, its smooth extension equals `8/sqrt(2)`. Its weak operator is exactly `splitGrushin 4 spectatorBasis B`. The coefficient `c=4` and the factor `8/sqrt(2)` are derived; neither is supplied as a physical premise.

`PairKSSpace` has the existing ordinary product norm and actual product Lebesgue measure. The chart is a KS lift, not a volume-preserving map from seven to six dimensions. Physical AE equality is used to obtain the original continuous representative and physical pointwise equation; it is not pulled back through KS as an arbitrary AE identity. The weak equation then follows by product-volume integration by parts and removability. The joint-H² assembly uses the frozen exact `WithLp 2` Fourier transport instead of identifying the ordinary product norm with a joint Euclidean norm.

## 3. Exact domain and selected-collision coverage

The literal coefficient patch is

```lean
def pairKSCoefficientPatch : Set PairKSSpace :=
  {q | ∀ j : Fin 2, position (pairKSLift q) j ≠ 0}
```

It is open and excludes both original nuclear collisions. It does not exclude the selected pair collision. In this two-electron setting there are no other electron pairs. The physical nuclear denominators are smooth on this exact patch, including `Y=0`.

The coverage theorem has the exact type:

```lean
theorem pairKSLift_covers_isolated_pair_collision (x : Configuration 2)
    (hpair : position x 0 = position x 1)
    (hnuc : ∀ j : Fin 2, position x j ≠ 0) :
    ∃ q : PairKSSpace, q.1=0 ∧ pairKSLift q=x ∧ q ∈ pairKSCoefficientPatch
```

It constructs the actual center spectator from the existing configuration product equivalence and reconstructs the original configuration by the Hadamard involution. The chart therefore represents every physical isolated pair collision away from the nucleus, with its transverse coordinate equal to zero. This is not a finite covering theorem for the entire collision arrangement or a treatment of simultaneous nuclear/pair collisions.
