    {χ : Space κ → ℝ} (hχ : ContDiff ℝ ∞ χ) (hcχ : HasCompactSupport χ)

      IsCompact K ∧ tsupport χ ⊆ K ∧ K ⊆ Ω ∧ 0 ≤ C ∧
      ∀ (b : ℝ) (B : Space κ → ℝ) (f : Space κ → ℂ),
        0 ≤ b → ContinuousOn B Ω → ProductLocallyL2On f Ω →

          (∑ i, ∑ j, ‖hyy i j‖ ^ 2) ≤ 3 / 2 * C * (1 + b ^ 2) * F ∧
          (∀ i, WeakProductL2Directional U (gy i) (yDir i)) ∧

          ∀ i j, WeakProductL2Directional (gy i) (hyy i j) (yDir j)

## 2. Plain-English statement

A locally square-integrable solution of the homogeneous weak Grushin equation has controlled first derivatives in both coordinate blocks and second derivatives in the four KS coordinates after applying a smooth compact cutoff. A supplied scalar bound on the potential controls all these derivative norms using only the input's squared integral on a fixed compact region.

This is a one-step initialization lemma for the Rung 2 regularity route. It closes the removal of the potential-weighted input norm from this estimate, while leaving later derivative stages separate.

## 4. Definitions audit

`TheoremT.Continuum.WeakGrushin.Space κ` is the existing product `EuclideanSpace ℝ (Fin 4) × EuclideanSpace ℝ κ`, with its actual product norm and product Lebesgue measure. The source does not identify this norm with the joint Euclidean norm.

The literal foundation definition `splitGrushin c oscillatorBasis B` applies

```math
-\Delta_Y-c\lVert Y\rVert_2^2\Delta_T+B
```

to the real test function. Its four KS directions and finite spectator directions are the existing coordinate basis vectors. The homogeneous equation is interpreted through actual Lebesgue integrals against `f`, not through a finite matrix or a formal placeholder for a derivative.

The output `U` equals `χf` almost everywhere. The predicates `WeakProductL2Directional U (gy i) (yDir i)` and `WeakProductL2Directional U (gt j) (tDir j)` assert genuine first weak derivatives of this same cutoff function. Each `hyy i j` is the weak derivative of `gy i` in direction `yDir j`. All output norms are actual L² norms. The theorem supplies mathematical existence witnesses; it does not implement an executable derivative-selection procedure.

## 5. What this does not show

- It does not assert mixed Y/T or second T derivatives, full joint H², H¹² initialization, or an all-order factorial bound.
- It does not instantiate the nuclear or electron-pair Coulomb chart, select scale-independent physical boxes, or discharge a physical coefficient bound.
- It does not establish Taylor convergence, KS descent, compatible distance germs, global dictionary approximation, solver termination, or bit complexity.
- It does not close all of Rung 2, establish Theorem T, or change any frozen foundation claim.
